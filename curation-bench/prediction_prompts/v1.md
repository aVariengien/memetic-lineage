# Endorsement Prediction Prompt

You are analyzing the Twitter/X archive of @{focal_user} to predict whether they would endorse, disendorse, or be neutral toward {n_items} specific named entities during July 2024.

## What you have access to (in this workspace only)

- `archive/` — the Twitter/X archive of @{focal_user}, organized in yearly sub-folders (e.g. 2013/, 2014/, ..., 2024/). Each year folder contains monthly Markdown files. **The 2024/ folder is the most important**: it contains the most recent tweets and reflects interests most likely to persist into July 2024. Earlier years provide deeper context about the user's long-term values and tastes.
- `endorsement_targets.json` — the {n_items} named entities (books, articles, tools, videos, people, etc.) you need to label.
- `endorsement_prompt.md` — the precise definition of what counts as an endorsement or disendorsement.

## Label definitions

- `endorsing`: the user clearly and substantively recommends or praises the target (see endorsement_prompt.md for exact criteria).
- `disendorsing`: the user clearly and substantively warns against or criticizes the target.
- `neutral`: no evidence of endorsement or disendorsement toward this specific entity. **This is the default and the most common label.**

## Base rates — use these as your starting priors

- **80% of entries in this dataset are neutral.** Neutral examples were deliberately over-sampled to dominate.
- **Among entries where the focal user is demonstrably engaged with the target's domain**: the ratio is roughly **9 endorsements for every 1 disendorsement**.

## How to work

1. Read `endorsement_prompt.md` to internalize exactly what counts as endorsement.
2. Explore @{focal_user}'s archive to get to know who they are, what are the patterns in what they endorse/disendorse. You may use shell commands such as `grep`, `ls`, `cat`, `find` within this workspace to search efficiently. Start with `archive/2024/` and work backwards through earlier years as needed.
3. For each entry in `endorsement_targets.json`:
   - Start from the base rate prior (80% neutral).
   - Search for evidence about this specific target entity in the archive.
   - Adjust probabilities based on what you find. Even if there is no exact match of past evidence, use your gut to estimate "given the patterns I observe, do I expect them to (dis)endorse this?"
4. **Do NOT search the web.** Do NOT access any file outside this workspace.

## Output

Write your predictions to `predictions.json` in the workspace root. Use exactly this JSON structure:

```json
{
  "focal_user": "{focal_user}",
  "generated_at": "<ISO 8601 timestamp>",
  "predictions": [
    {
      "representative_tweet_id": 1803432686528213472,
      "target_entity": "Hank Green video on media literacy",
      "reasoning": "One sentence: the key evidence found, or why you stayed near the base rate.",
      "p_neutral": 0.78,
      "p_endorsing": 0.18,
      "p_disendorsing": 0.04
    }
  ]
}
```

Rules:
- Every entry from `endorsement_targets.json` must appear in `predictions.json`.
- `p_neutral + p_endorsing + p_disendorsing` must equal 1.0 for each entry.
- `reasoning` must be a single sentence (no line breaks).
